# Procédure simplifiée de gestion d'incident

## 1. Détection

L'incident peut venir de la supervision, d'un utilisateur ou d'une alerte sécurité.

## 2. Qualification

Identifier :

- service touché ;
- nombre d'utilisateurs concernés ;
- criticité ;
- heure de début ;
- possible cause.

## 3. Contenir

Si c'est un incident sécurité, isoler le système si nécessaire sans détruire les traces utiles.

## 4. Corriger

Appliquer la correction ou le plan de reprise adapté.

## 5. Vérifier

S'assurer que le service fonctionne normalement et surveiller après le rétablissement.

## 6. Retour d'expérience

Pour un incident important, documenter la cause, ce qui a été fait et les actions pour éviter que le problème se reproduise.

Les incidents critiques doivent avoir une règle d'escalade claire vers les responsables concernés.
